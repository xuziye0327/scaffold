# scaffold

Project templates you can copy into a new repository. Each directory includes project files and agent development guidelines.

| Template | Description |
| --- | --- |
| `rust/` | A Cargo workspace for a Rust CLI and library |
| `vite-project/` | A React + TypeScript app with Vite, Bun, React Compiler, Oxlint, Oxfmt, and Husky |

## Line endings

The root `.gitattributes` sets LF line endings for text files. Each template has its own line-ending rules that stay with it when copied.
